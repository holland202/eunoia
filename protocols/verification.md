# Protocol: Verification

**Status:** PROPOSAL

## Purpose

Evaluate whether an outcome or claim meets stated criteria.

## Rules

1. Verification criteria are fixed before the result is known for confirmatory work.
2. Verification is independent of generation where practical.
3. Failed verification → result is not promoted.
4. Verification status is itself attestable.

## Axes (when applicable)

Separate mathematical, implementation, and empirical checks.
Do not report a single PASS that conflates axes.
