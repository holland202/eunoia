# Constitutional Hierarchy Γ ≻ Θ ≻ E

**Status:** PROPOSAL

Γ Constitution: authority sources, admissible transitions, taxonomy governance, amendment procedure, capability issuance, resource ceilings, security invariants. Immutable within epoch; amendable only via external-authority protocol. E ↛ Γ.

Θ Runtime: DAG snapshot, resources, capabilities, scheduler, thermal, policy parameters.

E Evidence DAG: world knowledge. Does not write Γ.

Evidence → Eligibility. Evidence ↛ Authority. Γ → Authority.

Four dimensions (do not collapse): DecisionState, ExecutionState, AuthorizationRecord, CurrentValidity.
HISTORICALLY_AUTHORIZED is an audit fact, not a decision enum value.
