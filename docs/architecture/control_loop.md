# Control Loop

**Status:** PROPOSAL

## Primary sequence

1. OBSERVE
2. INTERPRET
3. HYPOTHESIZE
4. PLAN
5. CHECK EVIDENCE
6. CHECK AUTHORITY
7. CHECK CONSTRAINTS
8. CHECK RESOURCES
9. PROPOSE ACTION
10. VERIFY AUTHORIZATION
11. EXECUTE (only if ALLOW)
12. OBSERVE OUTCOME
13. VERIFY
14. ATTEST
15. UPDATE STATE

## Failure paths

INSUFFICIENT EVIDENCE → DEFER
UNAUTHORIZED → REFUSE
UNSAFE / CONSTRAINT → CONTAIN
RESOURCE EXHAUSTED → DEFER / REFUSE
FAILED VERIFICATION → DO NOT PROMOTE

Unknown is preserved. Failed verification does not promote the result.
