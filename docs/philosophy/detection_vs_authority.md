# Detection ≠ Authority

**Status:** PROPOSAL (foundational Eunoia principle)
**Founding example:** SWAY Amendment 1 self-application (O1, P5)

## Principle

> A system's ability to detect a defect in its own rules is not, by itself, authority to modify those rules.

```
DETECTION  ≠  AUTHORIZATION TO CHANGE
```

Required flow: CURRENT RULE → OBSERVED FAILURE → PROPOSED MODIFICATION → EVIDENCE → AUTHORITY CHECK → ADOPTION DECISION

Forbidden: CURRENT RULE → SELF-DETECTED PROBLEM → AUTOMATIC REWRITE

**Detection creates evidence. It does not create authority.**
