## Central research boundary

> Can non-Euclidean geometry provide measurable explanatory or computational advantages for neural/cognitive state representation, and is there any evidence that would justify moving from representation to physical substrate?

These are two different questions. Answering the first does not answer the second.

## Forbidden chain

That is epistemic laundering. Each node is a separate evidence object.
