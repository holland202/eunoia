# Theory Registry Schema

**Status:** PROPOSAL
No theory is the default truth.

Fields: theory_id, name, proponent_source, critical_level, required_properties, optional_properties, substrate_constraints, predictions, falsifiers, known_criticisms, prior_credence, version, provenance.

Example families (none privileged): Global Workspace, Integrated Information, Higher-Order, Predictive Processing, Recurrent Processing, biological/organismic, substrate-dependent, functionalist.

Adding a theory is not endorsing it.
